## 1. 個人演技数が実装時の件数以上（減っていない）

```
実測 {'nishinihon': 1947, 'osaka_pweb': 1293, 'sporttech': 5969}
実装時 {'sporttech': 5969, 'osaka_pweb': 1293, 'nishinihon': 913}
増えたぶん {'nishinihon': 1034}
```

- **sporttech 5,969** … 指示書の期待値どおり
- **西日本 1,947** … 第53回 913（指示書の期待値どおり）＋ 第54回 1,034。
  第54回は2026-09-07に追加。PDF 26本・47ページから451名×予選2本（902）＋決勝132演技を読み、
  印字されている数値17,044個と氏名・所属の文字列を並び順ごと突き合わせて一致を確認した
- **大阪府 1,293** … 指示書の期待値は 1,063 だが、これは古い数字。理由は2つ

| | 演技数 |
|---|---|
| 指示書の期待値（サマリーCSV） | 1,063 |
| ＋ 決勝（2026-08-08 に追加取得済み） | +266 |
| − 区分ページをまたいだ重複掲載 | −36 |
| **実測** | **1,293** |

重複掲載は 2025-05-10 第37回大阪府年齢別で、「09才～10才女子」と「10才以下女子」の
両方のページに同じ演技が載っていたものです（18名×2本。値は完全一致）。
`also_in_categories` に両方の区分名を残して情報を落としていません。

## 6. n<100 の審判は「データ不足」

```
既定母集団(予選通過者×完遂) 審判 118名 / うち n>=100 は 24名
辛め 4名・甘め 4名・中立 16名
```

指示書の見込み（22名・辛め甘め各5人前後）とほぼ一致しました。

画面では n が100未満の審判は、平均パネル差・中央値パネル差・標準偏差がすべて「—」になり、
傾向欄に「データ不足」と出ます（例：KOECHER Bernd n=97、葛西 志保美 n=90）。
n・大会数・シーズン数・カテゴリは、データ不足の審判にも表示しています。

母集団は画面上で切り替えられ、今どの条件かを常時表示します。

| 条件 | n≥100 の審判 |
|---|---|
| 予選通過者・完遂のみ（既定） | 24名 |
| 完遂演技のみ | 52名 |
| すべての演技 | 79名 |
