# 大阪府：2つの経路の突き合わせ

取り込みは中間CSV経由（`etl/sources/osaka.py`）。それとは別に元HTMLを直接読み
（`etl/sources/osaka_html.py`）、値が一致するかを毎回確かめています。
入力そのものが違うので、一致すれば中間CSVの列の読み替えが正しいことを、
解釈ではなく2経路の一致として示せます。
