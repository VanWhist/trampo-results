# 西日本の所属の切り詰め（測定と確定）

**このファイルは `python -m etl.build` が毎回作り直します。**

西日本の所属は、予選ではQ2のスコアと同じ行に印字されるため、**列幅を超えると切り詰められます**。決勝は所属が独立した行に印字されるので折り返すことができ、完全形が残ります。

## 2段で判定しています

1. **一次スクリーニング（幅）**：予選Q2行の所属の幅が 100pt 以上を候補にする。所属は右詰めで印字されるので、列幅いっぱい＝切り詰めの疑い。予選 391 行すべてを実測。閾値の根拠は、決勝突合で切り詰めと確定した件がすべて 101.1pt 以上だったこと（実測の最大は 110.6pt）
2. **確定（決勝突合）**：決勝ページから折り返しを結合して読んだ完全形 37種類と突き合わせる。同一形なら完全、前方一致で長い形があれば切り詰め。同じ大会・同じクラブなので誤爆しない

幅だけでは候補しか出せませんが、決勝突合は白黒がつきます。

## この方法の限界

- **予選にしか出場していない選手の長い所属**は、決勝に参照が無いので確定できません。その所属が実際に切り詰められていた場合、**完全形はPDFのどこにも存在しません**。ここが西日本の所属の精度の上限で、読み取り側では回復できません
- 切り詰められていても列幅に達しない所属は、一次スクリーニングに掛かりません

以前は sporttech の所属名との前方一致で測っていましたが、シンクロの連結所属で誤爆し、既知の実例（谷口 遼平）も検出できなかったため、この2段の方法に置き換えました。
