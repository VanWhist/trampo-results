## D. 4-4 Eの検算式が古い（「94.8%止まり・原因未解明」は解消済み）

指示書の式は着地減点Lを常に足す形でしたが、実際は技数で分岐します。

```
N = 10 : E = 20  − (位置1〜10 + 着地L) / 10
N < 10 : E = 2N  − (位置1〜N) / 10        ← 着地減点は乗らない
```

この式で**個人種目8,158件すべてが一致**しました（要確認 0件）。
指示書が「sporttechでは94.8%止まり／2026-05-23アジア選手権の技数10の演技に集中／原因未解明」
と書いていた不一致は起きません。

この分岐は位置別の隔離にも効きます。中断演技のスロット10（着地）は実施点に入らないので、
`着地` ではなく `未算入` に振り分ける必要があります。ここを間違えると検証済みCSVと1,347件ずれます。

## E. 4-4 合計の式が不完全

指示書は `合計 = D + E + T + HD − Pen` ですが、正しくは

```
合計 = D + E + T + HD + Bonus − Penalty − DPenalty
```

Bonus と DPenalty が抜けています。7,908件で完全一致しました（許容幅内の要確認も0件）。
指示書が言及していた「国際大会の0.3〜数点の未解明な差異19件」も出ませんでした。

## F. 減点に2つの単位がある件が指示書に無い

## G. 4-1-2 State のルールでは件数が合わない

指示書は「State==3 かつ NElements が明示的に0 も除外」でしたが、
**State==4（失格）で NElements==0 の250件も除外しないと8,500件になりません。**

実際に8,500件を再現するルールはこうでした。

- `State == 0` を除外
- `NElements` キーがあって値が0なら除外（State 3・4 どちらも）
- `NElements` キー自体が無いときは出場記録として含める（技数は空欄。1件だけ）

## H. 4-2「E6・E7が空でE8に実データ 6,179件」の内訳

6,179件は**全種目込み**の数でした。個人種目に限ると

- 6審判制（E1〜E5＋E8）… 3,945演技
- 4審判制（E1〜E4）… 1,998演技

現象の指摘（E1〜E5だけ読むと1審判分を落とす）は正しく、そのとおり実装しています。
なお ETotalsT_G のスロット **10・11 は水平移動（HD）の審判**で、1,408件に有効値があります。
指示書はここに触れていませんでした。

## I. 5-2「sporttechの9大会分は今すぐ埋まる」→ 実際は15大会

構想案が調べたのは16大会で、その後アジア選手権3大会・W杯2大会が加わっています。
24大会中15大会に審判氏名があり、**延べ174名**（うち個人種目のパネル差集計に乗るのは118名）。

あわせて構造が指示書の記述と違いました。

- 審判氏名は `event.json` ではなく **`stage_N.json` の `Judges`** にあります。
  event.json には `JudgesPanels` しかありません
- 2025-12-05 ジャパンオープンは67枠中41枠しか氏名が入っていません
- **`JudgesPanelID = -1` のステージがあります**（例：2026-07-24 全日本ジュニアの決勝）。
  審判氏名がある大会でも、そのラウンドの担当は特定できません
- パネルの27スロットのうち、**E判定として確定できるのは 0,1,2,3,4,7 だけ**です。
  スロット5は2,934回使われていますが ETotalsT_G には一度も値が入りません。
  スロット10・14・21・22 の役割も未特定なので、`slots` に生のまま持たせ、

## J. 5-2 の judge_id は大会ごとにすると意味を失う

## K. 7-2 の母集団「予選通過者」の解釈

決勝出場者だけに絞ると、全日本選手権・W杯（予選→準決勝24名→決勝8名の3段構成）で
通過者を8名まで絞りすぎます。**準決勝または決勝に進んだ選手**としました。

結果は n≥100 が24名（指示書の見込み22名）、辛め4名・甘め4名（見込み「各5人前後」）で、
指示書の想定とほぼ一致しています。

なお Stage.Kind の意味は指示書に記載がありませんでした。実データから
**0＝予選／3＝決勝／6＝準決勝** と判定しています（Kind=6 は各区分24名で、
予選65名→24名→決勝8名の構造と一致）。Kind 7・8 は DMT/TUM にしか出ないため未判定です。

## M. 西日本のD空欄は欠測ではなく0

PDFは0を印字しないため、予選1本目のDは381行が空欄です（規定演技）。
欠測扱いにすると合計の検算が落ちます（城 瑛斗 予選1本目：0+17.10+14.37+9.90=41.37）。
0として採用し、`correction_flag` に「D空欄を0として採用（規定演技）」を残しています。

## 補足：指示書の指摘が正しかったこと

念のため、実データで裏が取れたものも書いておきます。

- **デデュープ必須**（`stage_<N>.json` は関連ステージのデータを重複して持つ）… そのとおり
- **種目は親Competitionの Discipline を使う**（Performance側は0固定の例がある）… そのとおり
- **大会名・日付は `_meta.json` を正とする**（`EventTitle_G` は国際大会で表記が違う）… そのとおり
- **単位換算**（÷1000・÷10・÷10・÷1000・÷100）… そのとおり
- **技数を超えた位置に非ゼロの減点が入る**… そのとおり。生JSONでは実際に入っています
  （v2 CSVでは既に `未算入減点` に隔離済みだったので、CSVだけ見ると気づけません）
- **`100` と `0` は審判なしのプレースホルダ**… そのとおり
- **大阪府サマリーCSVの列名が1つずつずれている**… そのとおり。1,063行すべてで検算一致
- **名寄せは氏名だけ**… そのとおり。所属も生年月日も鍵にすると分裂します
